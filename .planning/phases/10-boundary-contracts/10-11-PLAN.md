<objective>
Fix the THIRD recurrence of the Copilot CLI real-token-usage gap (10-UAT.md gap 1,
`fix_update_2026-07-06_THIRD_RECURRENCE`): `cli_adapter.py`'s `review()` method
pre-creates the per-call OTEL path as an empty directory via `tempfile.mkdtemp()`
before the Copilot subprocess runs. The real, CI-pinned Copilot CLI 1.0.67 file
exporter writes a single FILE at the exact configured path and only creates it
when that path does not already exist — a pre-existing directory at that exact
path makes the exporter silently no-op (confirmed via direct local reproduction
against the real binary; see `.planning/debug/copilot-otel-real-capture-recurrence.md`
"THIRD Recurrence" section).

Purpose: unblock real (non-`~est`) token/cost reporting for copilot-cli reviews in
production CI — this is the last blocker after two prior, code-level-verified but
live-incomplete fix rounds (10-09 parser rewrite, 10-10 `-p`/argv delivery mode).

Output: `otel_path` construction changed to a non-filesystem-touching unique path
(`os.path.join(base_otel_dir, f"{uuid.uuid4().hex}.jsonl")`), preserving per-call
isolation without pre-occupying the exact leaf path. Regression test updated to
assert the path is never pre-created, so this exact bug cannot silently reappear
a fourth time.
</objective>
